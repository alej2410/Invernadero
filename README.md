# Sistema de Gestión para Invernadero 🌱

Aplicación de escritorio desarrollada en Python con interfaz gráfica para gestionar clientes, pedidos, abonos e inventario de siembras.

## Características Principales
* **Directorio de Clientes:** Registro detallado con motor de búsqueda inteligente.
* **Gestión de Pedidos:** Control de plantas, fechas de siembra y entrega estimada.
* **Sistema Financiero:** Registro de deudas, pagos y abonos parciales.
* **Reportes Automáticos:** Generación de listas de deudores e inventario activo en tiempo real.

## Tecnologías Utilizadas
* **Lenguaje:** Python 3
* **Interfaz Gráfica (GUI):** CustomTkinter
* **Persistencia de Datos:** JSON local
